# Temporalización del Módulo Intensivo (50 Horas)

El módulo se estructura en dos fases claramente diferenciadas: **40 horas de aprendizaje y prácticas independientes** más **10 horas de proyecto final integrador** sobre una aplicación web empresarial.

```text
┌────────────────────────────────────────────────────────────────────────────────────────┐
│ FASE 1: APRENDIZAJE Y PRÁCTICAS INDEPENDIENTES (40 Horas)                              │
├────────────────────────────────────────────────────────────────────────────────────────┤
│ Bloque 1 (Semanas 1-2): [10h] UD1 - Integración de LLM en Aplicaciones                 │
│                               (APIs locales, Mensajes/Roles, Contexto, JSON, Pydantic) │
│ Bloque 2 (Semanas 3-4): [12h] UD2 - RAG y Acceso al Conocimiento                      │
│                               (Embeddings, pgvector, Permisos en SQL, Citas, Eval)     │
│ Bloque 3 (Semanas 5-6): [10h] UD3 - Tool Calling y Acciones Controladas                │
│                               (Tríada de control, Tipos de operaciones, Auditoría, MCP)│
│ Bloque 4 (Semana 7):    [ 8h] UD4 - Integración, Seguridad y Control                   │
│                               (FastAPI, Contratos, Fallos, Multimodalidad, Langfuse)   │
├────────────────────────────────────────────────────────────────────────────────────────┤
│ FASE 2: PROYECTO FINAL INTEGRADOR (10 Horas)                                           │
├────────────────────────────────────────────────────────────────────────────────────────┤
│ Bloque 5 (Semanas 8-9): [10h] UD5 - Integración de IA en una Empresa Cerámica         │
│                               (Catálogo RAG, Visualizador Multimodal, Asistente CRM)   │
├────────────────────────────────────────────────────────────────────────────────────────┤
│ TOTAL:                  [50h]                                                          │
└────────────────────────────────────────────────────────────────────────────────────────┘
```

> *Estructura en repositorio:* Los 5 bloques del curso (UD1 a UD5) se corresponden de manera directa y unívoca con los directorios `UD01_servicios_ia_locales`, `UD02_aplicaciones_rag`, `UD03_agentes_inteligentes`, `UD04_apis_y_despliegue` y `UD05_proyecto_final`.
